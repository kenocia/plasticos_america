Installation Guide

Installation

1. Install the required Python library:

  • sudo pip3 install slackclient
  • sudo pip3 install html-slacker

2. Install the bhs_odoo_x_slack_connector module in Odoo.

3. Restart Odoo to apply the module changes.

Configuration

  • Register a Slack App: Obtain the Client ID, Client Secret, and User OAuth Token from Slack.
  • Configure Slack Workspaces: Add and manage multiple Slack workspaces in the Slack Connector menu.
  • Set Up User Preferences: Define notification settings for users who want to receive alerts via Slack.
  • Enable Automatic Notifications: Configure Odoo's notification system to send messages directly to Slack users or channels.

FAQs

1. What does the Odoo x Slack Connector module do?

This module allows Odoo users to receive system notifications via Slack, ensuring instant and efficient communication. Notifications can be sent to Slack channels or individual Slack users, helping teams stay updated without constantly checking Odoo.

2. How do I connect my Slack workspace to Odoo?

To connect Slack with Odoo, follow these steps:

  • Register a Slack App on the Slack API Portal.
  • Retrieve the Client ID, Client Secret, and User OAuth Token from Slack.
  • Input these credentials in Odoo's Slack Connector settings to establish a connection.
3. Can I receive notifications in multiple Slack workspaces?

Yes! The module supports multiple workspace connections. You can configure different Slack workspaces in the Slack Connector menu, allowing notifications to be sent across various teams and channels.

4. How do I configure user notifications?

Each user must go to User Settings and select Handle by Slack in the notification preferences. They also need to input Slack User Config to ensure the system can send messages directly to their Slack account.
